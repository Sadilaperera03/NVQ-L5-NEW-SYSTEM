LEARNINGHUB NVQ LEVEL 05 — SIMPLE, FRIENDLY DESIGN UPDATE

Changes:
- Calm rose, warm peach and soft ivory palette; accessible dark palette
- Smaller hero areas, softer cards, cleaner headings, simpler quick links
- Mobile responsive spacing and reduced-motion support
- Gentle reveal/hover animations, user theme preference maintained
- Existing Firebase, Admin, PDF and LMS JavaScript retained

Deploy:
1. Extract this zip.
2. Back up your current Netlify deployment.
3. Drag the extracted folder containing index.html into Netlify Deploys.
4. Recheck Firebase Authorized domains and publish firestore.rules only if it is the intended existing production rule set.
5. Test login, member pages, chat, profile, quizzes and admin management with separate accounts.

The site was not tested against a live Firebase project. Private PDF file URLs are still accessible on static hosting when known.
